How it works

01

Text vocabulary

TF-IDF across unigrams and bigrams picks up the language of scam posts. Urgency words, earning promises, vague role descriptions. Trained on 18k real postings.

02

Structural signals

Missing logo, no salary, short description, absent company profile. Legitimate employers consistently provide this. Scam posts don't.

03

Combined model

Logistic regression with SMOTE for class imbalance. Chose LR for interpretability. You can see exactly what triggered each flag.
